# 🎵 Audio Player

Audio player web me playlist, buton play/pause, shirit kohe (scrubber) që mund të tërhiqet,
kontroll volumi me klikim, dhe butona kënga paraardhëse / pasuese.

## 🚀 Si ta hapësh

Hap `index.html` në browser dhe kliko **Live Demo**. Shtyp butonin ▶ për të luajtur
këngën — luhen dy sample-t audio reale (`sample.weba`, `sample2.weba`) që vijnë me projektin.

**Kontrollet:** ⏮ kënga paraardhëse · ▶/⏸ luaj/ndalo · ⏭ kënga pasuese · kliko shiritin e volumit për ta ndryshuar · tërhiq shiritin e kohës për të kërcyer në një moment të këngës.
